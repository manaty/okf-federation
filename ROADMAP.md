# Roadmap

## 0.1 — Discovery and governance draft

- Root and member manifest.
- Minimal workspace bootstrap.
- Configurable roles and review policies.
- Freshness policy based on OKF v0.2.
- Drift taxonomy and multi-repository change protocol.
- Reference schema, validator, and fixtures.

## 0.2 — Interoperability

- Machine-readable validation result schema.
- GitHub and GitLab approval evidence adapters.
- Cross-repository link URI test vectors.
- CODEOWNERS and identity-provider resolver test vectors.
- Prospective validation across candidate PR revisions.

## 0.3 — Reconciliation

- Drift report schema.
- `Federated Change` profile and complete example.
- Source-change detection receipts.
- Generated-view provenance and reproducibility checks.
- Security threat model and prompt-injection fixtures.

## Before 1.0

- At least three independent organizational implementations.
- At least two interoperable validators.
- Multi-organization project governance.
- Compatibility and migration policy validated across two draft upgrades.
- Naming and trademark review.
